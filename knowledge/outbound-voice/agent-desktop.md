# Outbound Voice — Agent Desktop (Outbound Voice 172)
**Source:** Product Foundation Courses → Outbound Voice / 172 Agent Desktop (video transcript + Care Console demo) · **Help:** search `site:sprinklr.com/help care console voice widgets agent layout record page editor`

## What it is
The agent's **Care Console** for voice — omnichannel interaction on one screen (calls, email, web chat, social, voice) with **Customer 360**. A custom homepage of the most-used widgets → **fewer clicks → faster resolution → CSAT**. Three tabs: **Omni-channel interaction**, **Case details**, **Customer 360**. (See [[../care-console/overview]] for the general console.)

## Voice-specific widgets (outbound)
- **Conversation pane** — real-time transcript + channel events (outbound call initiated, SMS/email/WhatsApp sent, **channel switches** e.g. voice→SMS→WhatsApp).
- **Campaign detail widget** — campaign name, **lead detail**, segment/subsegment.
- **Guided Workflow / Smart Assist widget** — start a **guided workflow** to solve a query or assist the agent; **Smart Assist** lists the GWs shared with the agent → pick one to trigger (e.g. address change, info update).
- **Custom widgets** — customer info from multiple sources (demographics, email, contact, PAN for a bank).

## Guided workflows here
Predefined step-by-step stages (branching logic, conditional statements, approvals) to drive a task. **Benefits:** agent efficiency, **consistent brand response**, fewer complaints, better training, lower cost-per-contact, **channel-agnostic** (with channel-specific variations). (Built per [[../guided-workflow/overview]].)

## Demo agent journey (bank example)
Agent in **Ready** status → call **pop-up** (name, phone, details) → **auto-answer** after a set time → Care Console + **live call controls** → widgets: **Profile** (ID, mobile), **Customer Demographic** (birthdate, gender, marital status), **Case Overview** (campaign name; "Show all" → case properties), **Campaign details** (segment/subsegment/city), **Lead details**, **Call history**, **Live Offer** widget (e.g. 2-wheeler/personal loan, credit card) → **Proceed** opens a **guided workflow** (assisted/unassisted journey; unassisted → pick an SMS template → send → Next) → **Next Best Action** widget (e.g. "credit card limit not utilised" → pitch). A **Switch console view** button reveals Lead History, Customer Engagement, Last Interaction, Financial Summary, Smart Assist.

## Layouts
Layouts vary by client (the 3 tabs are standard, but you can have e.g. 2). Configured via the **Agent Layout tool = Record Page Editor**: clone a layout, preview, edit, add widgets. (Same editor as [[../guided-workflow/record-page-basics]].)

## Notes / gaps
- This is the **outbound voice flavour** of the Care Console — the widget set (conversation/campaign/lead/live-offer/next-best-action) is what differs from the generic console.
- Smart Assist + Guided Workflow widgets are the agent's action surface; layouts are tuned per campaign via the Record Page Editor.
- Largely overlaps the Care Console module; cross-reference rather than treat as a separate product.
