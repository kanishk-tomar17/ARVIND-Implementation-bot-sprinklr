# Callback (Outbound Voice 173)
**Source:** Product Foundation Courses → Outbound Voice / 173 Callback (video transcript + demo) · **Help:** search `site:sprinklr.com/help callback schedule ACW callback manager`

## What it is
**Scheduling a call to a customer for a later time** (part of the **ACW** module). Customers called out of the blue may be reached at a bad time, or have a complex query the agent can't resolve immediately — so the agent **reschedules** for a time that suits both → higher resolution/sales rates.

- **Benefits:** efficiency (agents keep moving through the lead list instead of getting stuck), improved service, **reduced hold time** (continue another day vs hold/transfer), flexibility/convenience, and **workflow management** (reminders + **auto-dial at the scheduled time** so leads aren't missed).
- **Use cases:** technical support (involve an SME / need more time), sales & lead gen (involve managers/stakeholders later), **appointment scheduling** (healthcare/hospitality), escalation management (loop in a supervisor).

## Scheduling a callback (agent)
1. The agent home page has Home, Query Console, Reports, Cases, and **callbacks/schedule** widgets (+ help articles).
2. Make a call (status **Available** → Call → manual dialer → number). Customer says "not a good time" → hangs up → **ACW pops up**.
3. In ACW: disposition **Connected**, sub-disposition **Follow up**, set the **callback date & time** (calendar, e.g. 8:30 PM) → **Save/Submit**.
4. The **Schedule** on the homepage shows that callback plus all callbacks the agent has scheduled.

### Rescheduling (agent)
Hover a case in the Schedule → **Cancel**, **View in Care Console**, or **Reschedule callback** → calendar → **assign to self / another queue / another agent** (add **notes** for the receiving agent) → change date/time.

## Callback Manager (supervisor)
A **supervisor** feature: view a **summary of all callbacks scheduled by their agents**, and **change time/status, cancel, or reschedule** (e.g. if the supervisor needs to join the call, or the agreed time doesn't suit them). Supervisor page → **Callbacks** → reschedule/cancel.

## Notes / gaps
- Two callback paths exist: the **ACW disposition → callback** (this topic) and the **journey/dialer scheduled-callback** in [[post-call-workflow]] / [[dialers]] — both feed the dialer's callback profile.
- Reminders + auto-dial mean scheduled callbacks re-enter the dialer automatically — agents don't manually track them.
- Callback Manager is part of the (un-ingested) **Supervisor Console** persona.
