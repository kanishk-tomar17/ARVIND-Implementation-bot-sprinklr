# Sprinklr Social — Knowledge Base

Distilled from **sprinklr.com/help** (Sprinklr Social area). Reference material for RaptorCX consultants configuring client environments. Each file cites its source help articles.

Sprinklr Social is a large area (~260 leaf sub-categories: publishing, engagement, reporting, ~40 channels, advocacy, distributed/local, rule engine, asset manager). This folder is built **sub-area by sub-area**; see `_help-catalog/catalog.md` for granular status.

## Sub-areas

### publishing/ ✅
The composer, scheduling, approvals, and content automation.
- `getting-started.md` — Quick Publisher, Advanced Publisher, Publisher Console, third pane, media upload, alt text, mentions, thumbnails, audience restrictions.
- `editorial-calendar.md` — calendar views and navigation.
- `automation.md` — outbound message rules (stop publishing, auto-respond, non-compliant keywords, custom translators, asset-expiry restrictions).
- `approval-workflows.md` — tiered + parallel approvals, approval paths, rule-engine-driven approval, post-approval publishing scenarios.
- `ai-in-publishing.md` — Sprinklr AI+ content/alt-text/thumbnail generation, Smart Approvals, Smart Scheduling.
- `advanced-media.md` — emojis, GIFs/stickers, video (ProRes, monetization, optimization, captions, TikTok disclosure).
- `advanced-publishing-ops.md` — A/B testing, content placeholders, character limits, spell/grammar, custom dictionary, dark posts, broadcast, deactivated-account handling, TRAI SMS.
- `web-analytics.md` — Web Analytics profiles + UTM Manager.
- `know-more.md` — channel media guidelines, publishing permissions, FAQ, common publishing errors.
