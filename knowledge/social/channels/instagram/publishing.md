# Instagram — Publishing Posts (Sprinklr Social — Instagram)
**Source:** sprinklr.com/help — Instagram channel (multiple articles; see links below)

## What it is
- How to publish every Instagram content type from Sprinklr's Publisher: single **Photo/Video Post**, **Carousel**, **Reel**, and **Story** (direct or mobile).
- All content types are created in the same **Create Post** window — you pick the format in the **Type of Message** dropdown (Post / Story / Carousel / Reel).
- **Direct publishing requires an Instagram Business account** connected to Sprinklr. Regular (personal) accounts can only schedule or publish via mobile.
- Covers tagging people, collaborators, products, and locations — now independent functions in the Create Post flow.
- See also [[publishing]] for the cross-channel Publisher, [[asset-manager]] for media/DAM, and [[facebook]] for the linked Meta channel.

## Key features & how to use

### Publish an Instagram Photo Post
- Open Publisher: **Publisher icon** (top-right nav) → **Create Post**.
- **Select Accounts**: search/select your Instagram Business account in the **Select Accounts** field (use **Advanced Search** to filter). A red asterisk marks it as required.
- **Type of Message**: choose **Post** (dropdown also lists Story, Carousel, Reel).
- **Media**: under the Media block click **Select Media** (from Media Uploader / [[asset-manager]]) or **Upload Media** (from device). **Limit: only 1 media asset (Photo OR Video) at a time** for a single Post.
- **Tag People** (button under the media thumbnail): enter exact Instagram handles, click **Tag**. Only public accounts can be tagged.
- **Tag Products**: available on the media thumbnail (greyed unless product catalog is set up).
- **Caption**: type in the **Caption** field ("Add caption to your media"); use the **Emoji** icon and **Insert** menu. Counter shows the **2,200**-character limit. **Generate Web Analytics Links** dropdown adds tracked links.
- **Add Collaborators**: add up to 5 collaborator handles (independent of tagging — see Tags & Collaborate below).
- **Tag Location**: pick from the **Add location** dropdown.
- **Add Post to Sprinklr Link in Bio** (toggle): optionally add a redirect link / product tags.
- **First Comment** (optional): post hashtags/content as the first comment. Instagram allows **max 30 hashtags per post, counted across caption + comments combined**.
- **Disable Comments**: checkbox to turn off commenting.
- **Campaign / Tags / Social Bars**: associate Campaign (and Sub-Campaign), set Tags and Social Bars; optional **URL Shortener** and custom **Properties**.
- **Approval**: choose Approval Type, add an optional Approval Note.
- **Preview** in the right pane (toggle Mobile/Desktop).
- Publish: **Post** (publish now), **Save as Draft**, or **Schedule Post** (pick month/date/time → **Apply**; optional **Smart Scheduling**). **Publish Another** checkbox keeps the window open for the next post.

### Publish an Instagram Carousel Post
- Same entry path; set **Type of Message = Carousel**.
- **Publishing Type** appears: **Direct Publish** (Business accounts) or **Publish Via Mobile**. Helper text: "Instagram supports direct publishing of photos/videos only through Business accounts."
- **Media**: **Select Media** / **Upload Media** — add multiple assets (mixed photos/videos) for the carousel.
- Per-asset **Tag People** and **Tag Products** buttons sit under each media thumbnail.
- **Tag Location**, **Description** field, **Add Collaborators** (up to 5), **First Comment**, **Disable Comments**, Campaign/Sub-Campaign, Tags/Social Bars, URL Shortener, Properties, Approval — same as Post.
- Same caption limit (**2,200** chars) and hashtag rule (**30** across caption + comments).
- Publish / Save as Draft / **Schedule Post**; **Publish Another** to continue.
- **Carousel media specs:**
  - Images: JPEG, max **8 MB**, aspect ratio **4:5 to 1.91:1**, width **320–1440 px**, sRGB color space.
  - Videos: MOV or MP4, codec HEVC/H264, **23–60 FPS**, max bitrate **5 Mbps**, duration **3–60 s**, max **100 MB**, max picture size **1920 px** (horizontal).

### Publish an Instagram Reel
- Same entry path; set **Type of Message = Reel**.
- **Publishing Type**: **Direct Publish** or **Publish Via Mobile**.
- **Media**: **Select Video** / **Upload Video** — **max 1 video per Reel**. Single-video posts auto-convert to Reels on Instagram.
- **Change Thumbnail**: hover the video → **Options** → **Change Thumbnail** → pick frame → **Use this frame**.
- **Caption** (2,200 chars, Emoji + Insert + **Generate Web Analytics Links**).
- **Tag Users** field — "Add exact user handles" (info tooltip present).
- **Add Collaborators** field — "Add exact user handles" (up to 5; independent of Tag Users).
- **Audio Name** field — name the audio track (max **50** chars).
- **Tag Location**, **Share to Feed** checkbox (boosts reach), **Add Post to Sprinklr Link in Bio** toggle, **First Comment** (30-hashtag rule).
- If **Publish Via Mobile**: choose the responsible user in **User to notify**.
- Campaign/Sub-Campaign, URL Shortener, Properties, Approval, right-pane Preview, then **Post / Save as Draft / Schedule Post**; **Publish Another** to continue.
- **Reel video specs:** MOV/MP4 (MPEG-4 Part 14, no edit lists, moov atom at front); duration up to **15 min** (direct) or **90 s** (mobile); max width **1920 px**, aspect ratio **3:4 to 16:9**; **23–60 FPS**; VBR ≤ **5 Mbps**; max **300 MB**.
- **Reel limits:** tagging accounts and Instagram music stickers are **API limitations** (not supported); product stickers unavailable — use **Link in Bio** instead.

### Publish an Instagram Story — Direct Publishing
- Entry: **New Tab icon** → under **Sprinklr Social** select **Quick Publish within Engage** (or use the Publisher → Create Post).
- **Select Accounts**: Instagram Business account (required).
- **Type of Message = Story**.
- **Publishing Type = Direct Publish** (vs Publish Via Mobile). Helper text confirms direct publishing needs a Business account.
- **Media**: **Select Media** / **Upload Media** — **up to 10 assets (photos/videos combined)**. The screenshot shows a grid of up to 10 story frames; preview pane renders the vertical story with a **See More** swipe.
- **Campaign** (mandatory) + **Sub-Campaign**, **Set as Default** checkbox, **Tags**, **Social Bars**, **URL Shortener**, Properties, Approval (+ note).
- Tip banner: "When your media is ready to go, you can **pre-upload media to Instagram** to prevent a delay in posting."
- Preview (Mobile/Desktop), then **Post / Save as Draft / Schedule Post**; **Publish Another** to add more stories.
- **Story media specs:** Images JPEG, ≤ **8 MB**, **9:16** recommended (3:4 also allowed), sRGB. Videos MOV/MP4, **23–60 FPS**, **9:16** recommended, ≤ **100 MB**, ≤ **60 s**.
- **Story limits:** cannot add **stickers** or **overlay text/caption**; **polls, questions, and music are unsupported**; **resharing posts/stories** is unavailable — all API limitations.

### Publish an Instagram Story — Mobile Publishing
- Use when the account is not Business-direct-eligible, or you want native story tools (stickers/text/drawing).
- **Web app setup:** New Tab → **Quick Publish within Engage** → select Instagram account → **Type of Message = Story** → add up to **10 media assets** → enter description (Emoji Picker) → set the **User to notify** (who will publish on mobile) → complete required **Properties** incl. **Campaign** (mandatory) → preview → **Post** / Schedule (Calendar icon) / **Save as Draft**.
- **Mobile app:** open Sprinklr app → **Menu** (bottom-right) → **Publishing** (under Sprinklr Social) → search/select account → **Done** → **Create Post** → pick **Story** in the Template popup → **ADD FROM DEVICE** or **ADD FROM DAM** → write caption in **Write Caption** → **Next** → complete **Optimize** screen → **Save as Draft** or **Publish**.
- **Hand-off to native Instagram:** in-app notification → tap **Notification icon** → Details screen → **Publish On Instagram** → **Open Instagram** → add media to Story (caption auto-copied to clipboard) → customize (draw/text/stickers) → tap **Your Story** to publish → back in Sprinklr tap **Mark Post as Published** → confirm in popup → **Mark As Published**.
- **Requirements:** the notified user must have the native Instagram app and account access on their phone; Campaign is mandatory; stories expire after 24 hours.

### Instagram Tags and Collaborate
- Tagging and collaboration are now **independent functions** — you can add collaborators without tagging the same users.
- **Tag Users field:** tags people at specific positions within the post (where they were placed on the media).
- **Add Collaborators field:** adds up to **5 collaborators**; they are featured prominently in the **center** of the post. Each collaborator must accept the invite on Instagram for the post to appear on their profile.
- Both fields take **exact user handles** ("Add exact user handles") and show an info tooltip.
- **Supported on:** Post, Carousel, Reel (not Story).
- **Limits:** max **5 collaborators** per post; max **20 tags** per post.
- **Display behavior:**
  - Only tagged users → shown in their tagged positions.
  - Only collaborators → featured centrally.
  - Both → tagged users in their positions, collaborators centrally.

## Common issues & fixes
- **Direct publish unavailable / greyed out:** the account is not an Instagram **Business** account. Convert it or use **Publish Via Mobile**.
- **Hashtags rejected / dropped:** Instagram caps at **30 hashtags per post**, counted across caption AND first comment together — trim the total.
- **Story stickers/polls/music missing:** not supported via direct publishing (API limitation). Use **Mobile Publishing** to add native stickers/text/drawing.
- **Reel won't tag accounts or add music stickers:** API limitation; cannot be done from Sprinklr.
- **Product sticker on Reels not available:** use **Add Post to Sprinklr Link in Bio** instead.
- **Posting delay on Stories:** pre-upload media to Instagram before publishing to avoid lag.
- **Single video posted as Reel unexpectedly:** Instagram auto-converts single-video Posts to Reels — expected behavior.

## Notes & gaps
- **Prerequisite:** Instagram **Business** account connected to Sprinklr for any direct publishing. Personal accounts → schedule or Mobile Publishing only.
- **Permissions:** publishing/approval gated by the user's Publisher permissions and the post's **Approval Type** (workflow may route via [[rule-engine]] approval paths).
- **Carousel min/max asset count** is not stated in the source beyond "multiple"; Instagram's own platform limit is 2–10 (verify against current Instagram limits).
- **Story media specs vs Carousel/Reel specs** differ — confirm aspect ratios per content type before upload.
- Story articles' screenshots were largely local `blob:` references (not retrievable); steps captured from text + the one available Story screenshot.
- For analytics on published content see [[reporting]] and [[engagement-dashboards]].
