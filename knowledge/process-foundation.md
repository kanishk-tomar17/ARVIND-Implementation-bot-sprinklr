# Process Foundation — CCaaS Implementation Lifecycle (01)
**Source:** Product Foundation Courses → top-level `01_Process Foundation.mp4` (RaptorCX/Sprinklr internal CCaaS specialized-training session, Day 2; video transcript + "CCaaS-Docs Documents tracker" screenshot) · **Help:** internal document repository (Asana link circulated for latest digital + CCaaS docs)

## What it is
An internal training walkthrough of the **documentation and project lifecycle** used throughout a **CCaaS (Contact Center as a Service) implementation** — the same implementation process and lifecycle as digital deals, with a few extra CCaaS-specific documents. The CCaaS documents have been **merged on top of the existing digital documents** and reviewed by product owners/heads, so one common repository serves all upcoming implementations (digital + CCaaS).

## Project lifecycle stages
1. **Pre-Plan** — get a **Solution Design Template** (from the solution architect); **Sales-to-Success (S2S)** meeting with the **S2S checklist** (sales fills prerequisite info so the Services team has what it needs to deliver).
2. **Plan / BRW** — Business Requirements Workbook.
3. **Build** — configure to requirements.
4. **UAT** — user acceptance testing (incl. a dedicated **Reporting UAT**, treated as crucial).
5. **Go-Live.**

## Document repository (CCaaS-Docs tracker)
A tracker (Documents tab) lists each document with **Stage, Priority, Document Name, Description, CCaaS document link, Status**:
- **Runbook** (NA / High) — "**CCaaS Document Guide**" explaining how to use these documents at various stages of the project cycle.
- **SOW** (Pre-Plan / High) — Scope of Work.
- **Acceptance Criteria** (Pre-Plan).
- **Success Criteria** (Pre-Plan) — added in the SOW, referred to at UAT and go-live; evolves over the project.
- **S2S Checklist** (Pre-Plan / High) — ensures the Services team has the knowledge to deliver; PMs and ICs need it.
- (Plus other lifecycle docs — BRW, UAT checklists, etc.)
