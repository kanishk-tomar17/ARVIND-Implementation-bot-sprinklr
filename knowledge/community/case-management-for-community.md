# Case Management for Community (Community 186)
**Source:** Product Foundation Courses → Community / 186 Case Management for Community (video transcript + demo) · **Help:** search `site:sprinklr.com/help community case workflow profile level post level`

## What it is
Case workflows for community are **similar to any social channel** (Facebook, Twitter): a user creates a **post**, others **reply** (threaded comments) or create their own posts. There are **two ways** to configure case workflows for a community.

## 1. Profile-level cases
- Same as standard social channels. **All messages from a single profile are threaded into one case** — **across the whole community** (any post).
- Example: every post/comment from user "Master MDK" (on any thread) → one case; every message from user "Constructive" → a separate single case.

## 2. Post-level cases
- When a user **creates a post**, a **case is created** from that post.
- **All replies/comments** on that post (from the original poster **or** other users) get **threaded into the same case** as the original post.
- So the case bundles: original post → comment → next reply → etc., all on that one thread.

## Choosing
- **Profile-level** = one case per profile across the community (group by who).
- **Post-level** = one case per post/thread (group by topic/thread).
