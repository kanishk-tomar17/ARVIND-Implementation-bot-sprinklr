# Live Chat on Community (Community 183)
**Source:** Product Foundation Courses → Community / 183 Live Chat on Community (video transcript + demo) · **Help:** search `site:sprinklr.com/help live chat on community content settings`

## Why live chat on community
When a community user has an **urgent** request that can't wait for peer answers, **Sprinklr Live Chat** lets them chat with **brand agents** right away on the community for immediate resolution.

## Two ways to configure it
### 1. Content Settings → Live Chat section (no code)
1. In **Community Builder → Content Settings** tab, open the **Live Chat** section.
2. Toggle **Enable Live Chat** on.
3. Select the **Live Chat account** to configure (from the dropdown).
4. **Save** and **Publish changes** → live chat is configured on the community.

### 2. Embed the live chat code (global HTML/CSS)
1. **Content Settings → Global HTML & CSS** section.
2. Scroll to **"To be inserted before body tag"**, open the **HTML** section.
3. **Embed the Live Chat code** there (the JS embed from [[builder]]).
4. **Save** and **Publish changes** → live chat configured.
