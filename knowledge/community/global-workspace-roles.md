# Global & Workspace Roles & Permissions (Community 181)
**Source:** Product Foundation Courses → Community / 181 Global and Workspace Roles & Permissions (video transcript + demo) · **Help:** search `site:sprinklr.com/help community admin roles permissions care community`

## What it is
The **Community Admin** is a Sprinklr user who manages the community website, content, gamification, and the **end-customer** users/roles/permissions. This topic = giving that admin the right **Sprinklr-side** permissions via **global or workspace roles**.

## Modules a community admin needs permission for
- **Community Builder** (most important) — with sub-modules: **Page Layout**, **Branding**, **Category Hierarchy Management**, **Roles & Permissions** (for users), **Gamification**.
- **Sprinklr Publishing tool** — publish content directly from Sprinklr onto the community (no need to go into the community itself).
- **Care Reporting** — assess **community health** (new posts created, page views per page, new users joined, etc.).
- **Engagement Dashboards** — see a **stream** of incoming community messages; jump in and respond from Sprinklr.
- **Agent Console / Care Console** — only for **agents** managing the community (responding to cases).

## Create a role for community admin (demo)
1. **All Settings** → if **Workspace admin** you see **Manage Workspace**; if **Global admin** you also see **Manage Customer**.
   - **Global role:** Manage Customer → Global Roles → Create.
   - **Workspace role:** Manage Workspace → create a workspace role.
2. Top-right **Create Role** → name it (e.g. "Community Builder access").
3. In **Select Permission**, type **"Care Community"** → all community-builder permissions appear (view, create, edit, view topic, etc.).
4. Pick the permission set per use case:
   - Gamification-only group → **create badge, create rank, edit rank**…
   - Manage community users' roles/permissions → **create role, view role, update role, delete role**.
5. **Save** → role created. Create multiple workspace/global roles per client requirements.
