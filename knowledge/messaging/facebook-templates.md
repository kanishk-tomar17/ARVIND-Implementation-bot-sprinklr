## What they are
Facebook Messenger message templates let brands collect structured responses and present preset options. Two template types covered:

## Common build path
Create a new page → search **Assets** → **Digital Asset Management** → **Create Asset** → **Omnichannel Templates** → fill **Name + Description** → **Asset Specific:** Channel = **Facebook**, pick the **Template Type**.

## 1. Question with Answers template
Collects responses from the user in a structured way. **Two components:** the **Question** and the **Responses** (buttons).
- **Buttons** can be:
  - **Simple text response**, or
  - **CTA (action)** — three kinds:
    - **Redirect to Link** — send/redirect the user to a URL.
    - **Call** — give the user a number to call.
    - **Publish More** — add an **asset as a response** (can be another template).
- Then configure **asset details** (campaigns, expiry date) → **Save**.

## 2. Quick Reply template
Presents a preset set of options that appear prominently **above the composer**. When tapped, you get a text response from the user.
- **Two components:** the **Question** and the **preset responses (buttons)**.
- **Reply type** is a text response — add a **label**; optionally add an **image** to the quick reply.
- For each quick reply you can add **one asset** (e.g. a Question-and-Answer template as the asset).
- Add more quick replies → configure **asset details** (campaigns, expiry) → **Save**.
