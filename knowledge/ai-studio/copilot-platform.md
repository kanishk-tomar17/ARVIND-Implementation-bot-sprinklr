# Sprinklr Copilot Features for Platform (Sprinklr AI — AI Copilots)
**Source:** sprinklr.com/help — https://www.sprinklr.com/help/articles/platform/sprinklr-copilot-features-for-platform/6941562af0afa271d135f9fa

## What it is
- An AI-powered assistance layer that sits across the whole Sprinklr platform — a single, unified AI layer spanning Marketing, Service, and Social.
- Aims to improve usability, governance, and scalability across all modules.

## When to use
- A consultant or user needs guided help moving through a complicated, multi-step workflow.
- You want to offload repetitive admin work — tagging, routing, approvals — to automation.
- You need to keep actions compliant with the org's governance policies.
- You want real-time insight into performance metrics, system status, and user activity to optimise proactively.

## Configuration steps
The article does not document a full setup flow. The one concrete, configurable feature it lists:

1. **Sprinklr Assist** — enable and access:
   - **Enablement:** On request only (raise with Sprinklr to turn on for the environment).
   - **Access path:** Support > Universal Sprinklr Assist > View.
   - **AI+ Studio integration:** Not included for this feature.
   - **RBAC:** Role-based access control applies — gate visibility/use by role.

Core capabilities the Copilot delivers (no per-feature config steps given in the article):
- **Workflow navigation** — intelligent recommendations through complex processes.
- **Task automation** — tagging, routing, approval workflows.
- **Compliance management** — enforces governance policies.
- **Real-time insights** — performance KPIs, system status, user activity.
