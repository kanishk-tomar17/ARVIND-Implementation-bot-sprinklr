# Persona (Inbound Voice 157)
**Source:** Product Foundation Courses → Inbound Voice / 157 Persona (video transcript + demo) · **Help:** search `site:sprinklr.com/help persona app manager primary secondary footer`

## What it is
A **Persona App** = a **limited, focused set of tabs/modules** for a specific role, so the user isn't confused by the full platform. Provides a focused left-nav with required modules one click away, dedicated homepage items, and shortcuts.

## Standard persona types
- **Agent persona** — agents make/receive calls, see performance, compare with peers (leaderboard).
- **Supervisor persona** — live-monitor agents + **queue performance vs SLA**, manage traffic across voice channels.
- **Quality Manager persona** — monitor/evaluate agent performance and drive improvement.
- **Admin persona** — restricted tabs so admins do their work in one place (vs full classic view).

## Manage / create personas (demo)
- **All Settings → Manage Customer → Persona App Manager** — lists all enabled personas; set **sharing** per persona via the **share icon** → choose users / user groups / workspaces → Save (e.g. inbound agent to a set of users; supervisor to all supervisors).
- **Create** → name; choose a **template** (which persona to base it on, e.g. Insights & Care Agent / Care Supervisor); **product suite** (e.g. Sprinklr Service); **icon**; **description** → Next.
- **Menu items** in 3 areas: **Primary, Secondary, Footer**. Add items (e.g. Universal Search → Primary; Care Console → Secondary; Call icon → Footer) → **Update Draft**.
- **Preview** shows the persona's nav (only the defined items appear).
