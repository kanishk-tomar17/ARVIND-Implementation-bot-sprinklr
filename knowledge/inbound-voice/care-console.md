# Care Console (Inbound Voice 158)
**Source:** Product Foundation Courses → Inbound Voice / 158 Care console (video transcript + demo) · **Help:** search `site:sprinklr.com/help voice care console conversation widget outbound journey`

## What it is
**Care Console** = omni-channel agent workspace — agents handle calls, email, web chat, social from **one screen**, with the customer's profile + **previous case history across channels** visible. Fewer clicks → faster resolution, higher CSAT.

## Voice-specific Care Console
When a voice call is assigned, a **call pop-up** appears; agent clicks **Accept** → the Care Console opens. Voice-specific components:
- **Conversation widget** — **real-time transcript** of the agent↔customer call; also send **SMS / Email / WhatsApp** and **initiate an outbound call**.
- **Outbound Journey widget** — shows the **path the customer took on the IVR** before reaching the agent.
- **Guided Workflow buttons** — launch GWs to solve customer queries (see [[guided-workflows]]).
- **Custom widgets** — bring data from internal/external sources for a complete **Customer 360** on one screen.
