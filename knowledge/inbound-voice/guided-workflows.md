# Guided Workflows (Inbound Voice 159)
**Source:** Product Foundation Courses → Inbound Voice / 159 Guided Workflows (video transcript + demo) · **Help:** search `site:sprinklr.com/help guided workflow agent smart assist`

## What it is
A **Guided Workflow** = a set of customizable **steps** to complete a specific task/process, with **branching logic, API calls, conditional statements**, etc. Agents follow them while servicing customers. Brand admins track/measure GW performance in reporting and optimize.

## Benefits
- **Agent efficiency** (clear predefined steps → faster first-contact resolution); **consistency/reliability** (all agents follow the same steps); **fewer complaints** (less human error); **better/faster training & onboarding**; **lower cost per contact**; **channel-agnostic** (same GW works for email, chat, WhatsApp, **voice call**).

## Use cases
Take service requests (auto-create tickets), raise complaints, **agent troubleshooting** (e.g. IT support), fetch/update customer info, and **internal process automation** (trigger rules/other Sprinklr processes).

## Demo — Address Change GW (3 steps)
- **Configure:** Launchpad → **Agent Augmentation → Guided Workflows** → the GW "Address Change test" has 3 screens: (1) **verify** address + confirm intent to update, (2) **update** the address (with branching e.g. "moving to a different country?" → enter country; prompts telling the agent what to ask; capture address line/city/country/date), (3) **confirm** status of the change.
- **Agent use (live):** in a case (e.g. a Live Chat case) → **Smart Assist** → search the GW ("address change test") → click the **guided path** → the screens open; the agent walks through verify → update → confirm.
