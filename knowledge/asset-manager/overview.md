# Asset Manager (Digital Asset Manager / DAM) — Overview

**Source:** VERIFIED live (prod8, 2026-06-18) · **Help:** `site:sprinklr.com/help digital asset manager` (Digital Asset Manager → Getting started / Manage assets / Advanced Capabilities)

The central **repository for all assets** in Sprinklr — media, documents, templates, ad creatives, and Service assets like **Canned Responses, FAQs, Articles**. One place to store, organise (folders), approve, and reuse assets across modules.

## Access
- **Launchpad → Digital Asset Management** → URL `/marketing/asset-manager` (tab title "Asset Management").

## Views & top controls
- **View switchers:** Grid · List · Small / Medium / Large Cards.
- **Lifetime** (date-range filter), **Sort By**, **Hide/Show Filters**, **Refresh**, **More Actions** (bulk).
- **Create Asset** and **Upload a new Asset** (top-right).

## Create Asset — asset types you can author
Direct types: **Photo · Video · Post · Text · Document · Audio**.
Three items have **flyout sub-menus** (arrow ▸):
- **Templates ▸** Omni Chat Templates · Dynamic Image Template · Dynamic Video Template
- **Advertising ▸** Ad Creative · Canvas · X Card · Playable File
- **Advanced Options ▸** Font Family · Link · X Feedback Card · WeChat QR Code

(Plus **Upload a new Asset** for uploading existing files.)

## Filters (left filter rail)
**Author · Campaign · Source · Status · Type**, plus **+ Add Filter**.
- **Type** = the full asset-type taxonomy (large list), e.g.: Not Set, **Ad Creative, Ad Playable, Ad Targeting**, **Article**, Audio, Benefit, Business Contact, **Canned Response**, Canvas, Card, Default, Doc/Docx, EDB, EML, Encapsulated PostScript (EPS), Excel, **FAQ**, Font … (and many more — confirms DAM stores both marketing media *and* Service knowledge assets).

## Per-asset actions
- **Details**, **Edit**, **More actions**, **Add to Folder**.
- **Accept / Deny** — the **asset approval workflow** (assets can require approval before use).
- Assets organise into **Folders** (left tree with counts); folder-level actions exist (move, etc.).

## Why it matters (for consultants)
- Canned Responses & their **snippets** (used in Care Console reply box) are created/managed here as **Canned Response** assets — so "where do canned responses live?" → Asset Manager.
- FAQs/Articles surfaced by Smart Assist/Knowledge Base also live here as assets.
- Approval workflow + folders + permissions/restrictions govern reuse across teams.
