# Announcement Features (Supervisor Console 047)
**Source:** Product Foundation Courses → Supervisor Console / 047 Announcement Features (video transcript + Create Announcement form screenshot) · **Help:** search `site:sprinklr.com/help supervisor console announcements acknowledge reminder`

## What it is
**Announcements** are a **one-to-many** communication tool in the Supervisor Console — supervisors broadcast a message to their team(s).

## Use cases
Update agents (new offer to pitch), motivate/appreciate top performers, meeting reminders, align the team (e.g. "SLA is dropping — let's meet it"), proactively communicate during a crisis (e.g. website down → next steps for clients).

## Agent experience (the pop-up)
Agents see a pop-up with: **sender**, **image**, **title**, **content**, and two buttons:
- **Acknowledge** — confirm the announcement.
- **Set Reminder** — get reminded every **10 min / 1 hour / 1 day** (until the expiry date).

## Create an announcement
Supervisor persona → **Announcements** (left) → list of past announcements → **Create Announcement** → fill the form:
- **Announcement Image**.
- **Title**.
- **Description** — live **preview** shows how it appears to the end user.
- **Confirmation Text** — customizable acknowledgment button text.
- **Expiry Date** (date + time) — agents can't set reminders beyond this.
- **Workspace** + **User / User Group** (subscribers the announcement is intended for).
→ Save → agents receive the pop-up.

## Reporting
Announcement reporting shows two statuses per recipient: **Pending** (not yet acknowledged) and **Read/Confirmed** (clicked Acknowledge).

## Customer example
HDFC Bank uses announcements heavily — motivating agents, sharing high performers, and **gamification** (e.g. "make N sales → get this bonus"). Also used by Lenskart.
