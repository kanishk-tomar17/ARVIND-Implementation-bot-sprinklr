# Peer to Peer Chat Features (Supervisor Console 048)
**Source:** Product Foundation Courses → Supervisor Console / 048 Peer to Peer Chat Features (video transcript + "Peer to Peer Chat Overview & Benefits" slide + console chat panel) · **Help:** search `site:sprinklr.com/help peer to peer chat supervisor console internal communication`

## What it is
**Peer-to-Peer Chat** is an **internal unified text-communication** tool inside Sprinklr (like "internal WhatsApp") — care agents, supervisors, admins, and quality managers collaborate directly in the Sprinklr interface, eliminating third-party chat apps.

## Benefits
- **Everyday communication & collaboration** — agents seek support from supervisors; supervisors follow up on tasks and get status updates; consistency + approachability.
- **Share best practices / QM feedback** — after reviewing a recording / doing QM on a call, instantly share feedback + actionables with the agent.
- **Onboarding** — new agents ask their buddy / supervisor / quality manager questions.
- **Escalations** — create a **group chat**, add multiple agents/supervisors at once to collectively resolve.
- **Remote/hybrid workers** — keeps agents in different locations connected.
- **Usability** — no switching between Sprinklr and WhatsApp/Skype/Teams desktops; communicate within Sprinklr.

## How to use
- From a monitoring screen, on an agent's **⋮ → Send Message** → peer-to-peer chat opens with that agent.
- Or click the **+** icon → select the agent(s) → type messages.
- **Group chat:** **+** → add multiple agents at once → search/select users.
- **Send media** — upload and share an image.
- **Send a case number** — it's highlighted and **opens the case in Sprinklr** from the chat.
