# Home Page Features (Supervisor Console 042)
**Source:** Product Foundation Courses → Supervisor Console / 042 Home Page Features (video transcript + Supervisor Care console screenshot) · **Help:** search `site:sprinklr.com/help supervisor console home page widgets team status`

## What it is
The **Supervisor persona home page** gives a supervisor an at-a-glance view of team performance and status. It's composed of **widgets**, most shared directly from **Reporting** (configure a dashboard in Reporting → share it to the persona).

## Home page widgets
- **Performance Metrics (past 24h)** — e.g. number of calls offered, calls taken, any reporting metric. Click to **drill down** (total cases, user distribution, user-group distribution). "Show All" opens the underlying reporting dashboard; data mirrors the shared dashboard.
- **Team Status** — current status of each team member (Available / Unavailable / Busy, etc.).
- **Team Overview (past 24h)** — per agent: current status, **Average Handle Time**, or any chosen metric.
- **Escalated Cases** — click a case → opens the **Case Console** screen.
- **My Schedule** — scheduled tasks for the supervisor + team (upcoming / pending / cancelled).
- **Top Intents Volume** — custom widget (shared with the user).
- **Recently Viewed Dashboards** — quick re-open of recently/most-opened dashboards without searching Reports; opens in-persona (no tab switching).
- **To-Do** — supervisor (or any user) adds a personal task: description, due date, linked ticket/case, **priority** (e.g. Urgent); stays until cleared.
- **Recommended Articles** — knowledge-base articles shared within/outside the team; click to open the article portal.
- **Support Team** — click to open the mailbox to email a support issue (persona/agent-tab/any-tab issues).
