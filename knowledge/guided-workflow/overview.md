# Guided Workflow — Overview

**Source:** Product Foundation Courses → `Guided Workflow - Overview / 112_…` (video transcript) · **Cross-check:** `site:sprinklr.com/help guided workflow`

A **Guided Workflow (GW)** = a set of predefined steps/stages users follow to complete a task or process (e.g. troubleshooting steps), automatable and embeddable.

## What it does / why
- Automates a step-by-step process — embed in the brand's website/app for **customer self-service**, or give agents a step-by-step guide to drive **first-call resolution**.
- Can automate tasks: fetch customer info, update external CRMs, etc.
- Outcome: streamlined processes, better responsiveness, improved CX and brand loyalty.

## Two types
- **Agent-facing (internal)** — agents use it to resolve issues / guide the customer.
- **Customer-facing (external)** — embedded in brand website/app as a self-service guide.

## Configure a Guided Workflow
1. **Sprinklr Service → Agent Augmentation → Guided Workflows**.
2. **Create New Guided Workflow** → name + description → **Create**.
3. In the **GW canvas**, add **nodes** from the list (each node type covered in its own micro-skill).
4. **Settings (gear)** → enable **Progress Bar** (agent sees overall progress while executing on Care Console).
5. **Save as Draft** (saved but not executable) vs **Save and Deploy** (executable).
6. **Activity** menu on an existing GW: **Activity** (who changed what), **Version History** (view/revert to a prior version), **Reports** (initiated account + usage trend).

## How to trigger / execute a GW
Multiple entry points:
- **Case control button** (pinned button on top bar)
- **Agent Nudge** (when the nudge includes a GW button)
- **Smart Assist widget** (search the GW name → initiate; also via View Case → Smart Assist)
- **Guided Workflow widget**
- **Guided Path widget** (expand → follow)
- **Third pane**
