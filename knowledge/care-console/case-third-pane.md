# Care Console — Third Pane (case / profile / message detail)

**Source:** Product Foundation Courses → `Care Console - Case Third pane` (video `039_…`, transcript read) · **Cross-check:** `site:sprinklr.com/help third pane`

The detailed-view panel for a **case, message, or profile**. Agents get a quick snapshot and drill into full detail.

## What it is
- Detailed view of a case / message / profile: case-level properties, profile-level widgets, activities, collaboration — all info available on that case/profile.
- **Quick peek** upfront; click **Show all** / **View case details** for the broader/detailed view of a widget, field, or section.
- Agents can **reply** from the third pane and take actions: **apply macro, assign case, set reminders**, etc.

## New vs Old third pane
- **New third pane** = enhanced UI with **tab segregation** (Properties / Overview / Conversation / Activity tabs) — click a tab to jump straight to that info. Organised, less clutter.
- **Old third pane** = properties shown upfront; other info only via the three-dot menu; feels cluttered. **All new enhancements go into the new third pane; the old one will sunset.**

## Case third pane
- Overview of a case: **case properties, AI-generated case summary, case collaboration, case tasks**.
- Tabs/sections: historical cases, full conversation, properties; **Activity** via the three-dot menu.
- **Widget third pane**: for any widget (case history, linked cases, Smart Assist, custom widgets) click **Show all** → lands on that widget's full view (e.g. Smart Assist → all guided workflows / KB articles).

## Profile third pane
- Profile-level info: **profile properties** (distinct from case properties), profile notes, profile tasks, multi-channel profiles.
- **Cases** tab → all cases for that profile; **Historical cases** → past conversations **segregated by case number**.
- **Show all** on profile notes / profile activity → full list. Agents can view previous conversations and act on historical cases from the third pane.
