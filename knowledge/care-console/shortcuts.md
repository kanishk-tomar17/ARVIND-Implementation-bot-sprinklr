# Care Console — Shortcuts: Canned Responses & Macros

**Source:** Product Foundation Courses → `Care Console - Shortcuts` (video `033_…`, transcript read) · **Cross-check:** `site:sprinklr.com/help canned responses macros`

Speed tools in the agent desktop: **canned responses** (reply templates) and **macros** (one-click actions).

## Canned responses
- Pre-defined, **brand-compliant reply templates** for common/routine queries (e.g. "how do I add a credit card", "how to apply for a refund").
- Benefits: answer FAQs fast, protect the brand from rude/tone-deaf replies, cut agent response time (no typing).
- **Use:** in the reply box, click the **canned responses icon** → pick a template (added by senior agents/admins) → it's inserted → edit if needed → Send.

### Snippets (shortcuts)
- Snippets are **keyboard shortcuts** for canned responses. Admins define a snippet/shortcut when creating the canned response in **Asset Manager**.
- **Use:** type `/<snippet>` (slash + snippet name, e.g. `/almond`) in the reply box → matching responses appear → select → inserted → edit → publish.
- Difference: a snippet jumps straight to the response without searching the full list; plain canned responses show the whole shared list to search/select.

### Grouped canned responses
- Group templates into **folders** (e.g. shipping, inventory, returns, banking). Pick the folder → shorter list → select/insert/edit/send.

## Macros
- **Macros = shortcuts to perform a defined action** on the agent desktop in real time (e.g. close a case, assign a case, add a case to a list).
- **Use:** click the **Macro button** → search (e.g. "Close") → apply → fill required fields (e.g. sentiment) → action runs (e.g. case closed).
- **Favourite a macro:** click the **star** → it appears in an expanded **Favourites** folder (top ~4 most-used) for one-click access without searching.

## Quick macros
- A macro that **combines two different actions**, and **sits right next to the reply box** for fast access.
