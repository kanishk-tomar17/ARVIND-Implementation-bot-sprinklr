# Care Console — Channel-specific Layouts

**Source:** Product Foundation Courses → `Care Console - Layouts of care console based on channels` (video `037_…`, transcript read) · **Cross-check:** `site:sprinklr.com/help care console layout`

Default layouts differ per channel to fit each channel's needs. Managed in **Care Console Manager**; clone the default to customise without touching it.

## Why channel-specific
- Each channel has different needs, so the **conversation pane vs widget** split and widget set are tuned per channel to show only relevant info and optimise agent UX.
- Default layouts live in **Care Console Manager** (after Care Console is enabled + permission). To change: **Clone** → name it → edit (don't touch the default).

## Default layouts
**Social** (Facebook, Twitter/X, LinkedIn, Instagram)
- ~**50/50** split: conversation pane ~50% (40–50% depending on screen resolution), widgets ~50%.
- Default widgets: conversation pane, case details, profile card, customer happiness, workflow, properties, collaboration (more across tabs).

**Email**
- **65–70%** (up to ~75%) of screen to the conversation pane — because emails are long; prevents scrolling. One column for widgets (scrollable).
- Reply box is **larger** than on social for drafting long emails.

**Live Chat**
- Similar to others **plus a User Journey widget** — shows the customer's path on the website (pages visited, products viewed) so the agent infers intent and tailors the reply.
- Also supports **co-browsing** — agent views the customer's screen to diagnose and resolve quickly.

## Notes / gaps
- From the course video transcript. Splits vary with screen resolution; widgets can be added/removed per client need (in Care Console Manager). Related: `care-console/manager.md`, `care-console/widgets.md`.
