# Care Console — Collaboration Notes (case & profile level)

**Source:** Product Foundation Courses → `Care Console - Collaboration Notes` (video `038_…`, transcript read) · **Cross-check:** `site:sprinklr.com/help collaboration notes`

Internal notes for agents to get help and share context — at **case** level and **profile** level.

## What collaboration is
- Agents collaborate via **notes**, **@-tagging** team members / supervisors / admins to seek help on a case or profile.
- Tagged person is **notified**; clicking the notification lands them on that case to respond.
- Notes appear with a **yellow background** (to distinguish a note from a customer reply). Add via **Add note** in the conversation pane or the **Case Collaboration widget** (the two are synced).
- **Attachments** can be added to notes (case + profile level) for visual context.

## Case collaboration
- Exchange notes at the **case level** to ask questions about that specific case.
- Add from the **conversation pane** (saves clicks — note + reply from one place) or the **Case Collaboration widget** — synced either way.
- **Hide notes** (user-level): an agent can hide notes from the conversation pane so they only see the customer conversation there, and view notes only in the collaboration widget. Personal preference.

## Visibility control
- **Profile-level notes**: toggle visibility — visible to everyone, or restricted to a specific tagged person (e.g. only Benjamin). Case-level visibility control was noted as coming in a future release.

## CRM ↔ Sprinklr notes (bidirectional sync)
- Notes can **bidirectionally sync with a CRM** (Salesforce or any integrated CRM).
- **Add note** → choose **Add Sprinklr note** or **Add CRM note**. CRM notes show an **indicator** to distinguish them from Sprinklr notes. CRM notes appear on the CRM platform; in Sprinklr you see both — no switching back and forth.

## Profile collaboration
- Notes at the **user/profile level** to help any agent handle **future cases** for that profile.
- Profile notes show in the **Customer 360 view** by default (can also be placed in Omni-channel / Case Details).
- Example: "this user is fussy, give an extra 10% discount" — future agents see it upfront.

## Case vs profile notes — key difference
- **Case-level note** = belongs to that one case (only visible on that case).
- **Profile-level note** = belongs to the profile (visible across all that profile's cases).
