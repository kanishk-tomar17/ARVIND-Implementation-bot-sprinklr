# Care Console — Agent Assist (AI features)

**Source:** Product Foundation Courses → `Care Console - Agent assist - AI Features in Care Console` (video `034_…`, transcript + on-screen frames read) · **Cross-check:** `site:sprinklr.com/help agent assist`

AI (and non-AI) features that help agents reply faster, on-brand, and accurately.

## Smart Responses (AI)
- AI suggests full replies, trained on the **brand's historical agent responses** — matches the brand's salutation/format so little editing is needed.
- Stated accuracy **>80%** (because it's trained on that brand's own data).
- **Use:** pick a suggested smart response → **Insert asset** → edit if needed → Publish.

## Response Compliance (AI) — *seen on screen*
- AI checks each drafted reply against brand standards and flags issues in an **"Issues Found"** panel:
  - **No biased / discriminatory content** (flags bias along race/religion/gender/age).
  - **Relevance** — is the reply relevant to the prior conversation (e.g. "Relevance is High").
  - **Tone / Tonality** is proper; flags profanity.
  - **Incorrect Salutation** (e.g. flags "hi user" → "Use: Customer Name"); **Banking Jargon** flagged.
- Agent clicks **Correct Suggestion** to apply the fix, then sends.

## Smart Compose (AI)
- Inline autocomplete: as the agent types, suggested sentence-completion appears in **light grey** in the message background. Press **Tab** to insert in one click; edit or send as-is.

## Smart Assist (AI) — third pane widget
- Recommends, based on the conversation **intent**: **similar cases**, **knowledge base articles**, and **guided workflows** (shows top 3 of each in the widget).
- KB article actions: open/read, **copy URL** to send, or **Copy to response** (inserts the selected article text into the reply box → edit → send) — lets agents send steps/links fast.
- Guided workflows can be in the **agent's preferred/native language**; step through to resolution.
- **Show all** → full list (e.g. all 230 GWs) with search.

## Agent Nudges (AI)
- AI predicts customer intent in real time and surfaces the **next best action** proactively. Can also trigger on a **keyword** or **CSAT**. E.g. nudges to view similar cases matching the conversation intent.

## Why it matters
- All of the above improve **FRT/CRT** and **CSAT** by giving agents the right reply/info with minimal clicks and typing.
