# Reply Box AI Writing-Assist (Sprinklr AI+) — Care/Agent Console

**Source:** https://www.sprinklr.com/help/articles/agent-assist/reply-assistance/6450ce78d85662201933c7ea

Sprinklr AI+ options inside the **reply box** (Care Console / Agent Console). Agent selects drafted text → clicks the **Sprinklr AI+** icon → picks an option → reviews/edits → sends.

| Option | What it does |
|---|---|
| **Reword** | Rephrases/paraphrases the reply — changes grammar & vocabulary, keeps the same meaning/context |
| **Fix Spelling & Grammar** | Corrects spelling, grammar, and punctuation so the reply is grammatically correct |
| **Make it Longer** | Expands the reply, retaining context |
| **Make it Shorter** | Condenses to a crisper, more precise version |
| **Simplify Language** | Rewrites for broader accessibility/readability |
| **Modify Tone** | Rewrites in one of 6 tones: Professional, Relaxed, Empathetic, Bold, Persuasive, Luxury |
| **Translate** | Translates the reply into one of 8 languages: English, Mandarin, Spanish, French, German, Japanese, Italian, Arabic |

## Enablement
- Which options show up is **configurable per account** — raise a ticket to **tickets@sprinklr.com** to add/remove options.
- Agent needs **Sprinklr AI+ permission under Publishing** to see the icon at all.

## Related (separate feature, not AI+)
Native red/green-underline spelling & grammar checking is a **different, non-generative** capability — see [[spelling-grammar-check-outbound]]. AI+ "Fix Spelling & Grammar" rewrites via LLM; the underline checker flags inline as you type, works across all publishers, and supports a personal dictionary + pre-publish blocking rules.
