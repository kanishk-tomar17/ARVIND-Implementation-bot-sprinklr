# Care Console — Overview (Case Stream, Conversation Pane, Reply Box, Notes, Third Pane)

**Source:** Product Foundation Courses → `Care Console - Care Console Overview` (video `031_…`, transcript generated + read; on-screen demo observed) · **Cross-check:** `site:sprinklr.com/help care console`

The agent workspace. Four areas an agent works in: **Case Stream**, **Conversation Pane**, **Reply Box**, **Third Pane** (plus Notes).

## 1. Case Stream
A stream/list of cases showing the info an agent needs to decide what to pick:
- Case creation time, the customer's query/message, SLA / reply timers, priority.
- **Custom fields shown upfront on the case card** — configurable per brand (e.g. status, reason, brand, country, location, channel) so agents triage by what matters to them.
- **Filters**: narrow the stream by status (Open, In Progress), priority, or any relevant custom field — agents see only cases relevant to them.
- Click a case → opens its Conversation Pane + widgets.

## 2. Conversation Pane
The series of messages between agent and customer, with sender name, publish time, channel.
- Gives the agent the full conversation history.
- **Filter messages by message-level tags** to show only relevant messages.
- **Conversation-level actions** (three-dot menu): hide notes, view/hide activities, download attachments, **export conversation** (enter start/end date → export; default format CSV, opens in Excel; agent is notified when ready).
- **Message-level actions** (three-dot on a message): apply a macro to the message, review the message against a rule, set a reminder, or reply directly to that message (reply icon).

## 3. Reply Box (most important part of Care Console)
Where the agent composes and sends replies.
- Insert: replies from **Knowledge Base articles**, **canned responses**, **smart responses** (for speed).
- Rich text: highlighting and linking; insert images/videos; emojis; attachments; links.
- **Account selection** — choose which account to send from.
- **Private reply** — toggle to reply privately to the customer when the conversation is on a public forum/tweet.
- Choose reply type, then **Publish reply**.

## 4. Notes
- Click **Add note** → the compose area turns a **yellow background** (the identifier that you're writing a note, not a public reply).
- **@-tag** a colleague (e.g. tag a teammate for help) → they get notified.

## 5. Third Pane
Case/profile-specific information panel:
- Case properties, profile properties, collaborations, activity.
- Gives the agent a comprehensive snapshot of the case; supports actions like applying macros, archiving, setting reminders, and widget actions.
- (Real screen seen in the demo also surfaces a **Smart Summary Widget** — live predicted CSAT, average/last waiting time, current sentiment — plus **Customer Profile**, **Guided Path Widget**, and **Customer Lifetime Value** widgets.)
