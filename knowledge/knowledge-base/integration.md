# Integration — Consumption & Touchpoints (KB 128)
**Source:** Product Foundation Courses → Knowledge Base - Integration (Smart Assist, Smart Comprehend, Sprinklr AI+, Bot) → **"KB Microskills - Consumption & touchpoints" PDF** (slide deck; no course video) · **Help:** search `site:sprinklr.com/help knowledge base smart assist smart comprehend AI+`

## What it is
How Knowledge Base **articles** are **consumed across multiple Sprinklr products** — the integration/touchpoint map. KB is a central asset (a pyramid of articles) that other products draw from.

## Touchpoints (where KB is consumed)
- **Agent-facing consumption:**
  - **Knowledge Base Builder** — where articles are authored/managed.
  - **Care Console** — agents surface articles while handling cases (via Agent Assist / Smart Assist).
- **Public-facing consumption:**
  - **Community** — the public self-service portal (see [[community-builder]]).
  - **Live Chat** — articles surfaced to customers / used for deflection (see [[chat-deflection]]).
