## What it is
The **Knowledge Base Builder** is the central page to create and maintain the KB — articles, categories, content templates, content variables, language settings, and nominated messages.

## Access
**Launchpad → Resolve column → Knowledge Base.** Requires **View permission** under the Knowledge Base section of the Service Cloud module.

## Core features
1. **Create Categories** — top-right **Create Category**; organize content by product, service, issue type, team, region, or format (FAQs, troubleshooting guides, etc.). Supports sub-categories. *An article cannot be created without a category.*
2. **Create Articles** — select a category/subcategory → **Create Article** (top-right). Configure:
   - **Category/Subcategory** to file it under (mandatory).
   - **Content Sub-Type** — Article, Block, or Release Notes.
   - **Country** — for the mapped languages to be selected.
   - Optionally start from a **Content Template**.
3. **Search** — exact-phrase matching (quotes), keyword search with **title prioritization**, and logical connectors (and/or).
4. **Filters** — narrow results; save as **quick filters** (rename/share/delete); **pin** frequently used filters at partner level.
5. **Sort** — by Title, Modified On, Created On, or Content Modified Time (search defaults to relevance).
6. **Manage Columns** — choose/rearrange displayed columns, including custom article fields.
7. **Share Filtered Views** — generate a shareable URL capturing current query + filters + sort for collaboration.

## Builder configuration areas
From the Builder page you can also: configure **Content Templates**, define **Content Variables**, manage **Language Settings**, and handle **Nominated Messages**.

## Article types supported
- **Imported** — migrated from external repositories.
- **Native** — created in Sprinklr.
- **Nominated** — sourced from community messages.
- **External** — hosted elsewhere, copied into the KB.
