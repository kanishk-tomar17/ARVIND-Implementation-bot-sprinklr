# Organising & Creating Dashboards (Reporting 061)
**Source:** Product Foundation Courses → Reporting / 061 Organising and Creation of Dashboard (video transcript + Create Dashboard dialog screenshot) · **Help:** search `site:sprinklr.com/help care reporting create dashboard folders tags`

## What it is
How to create dashboards in **Care Reporting**, organize them with folders/tags/favorites, and keep the workspace navigable.

## Create a dashboard
1. Go to **Care Reporting** → **Create Dashboard**.
2. Fill the **Create Dashboard** dialog:
   - **Dashboard Name** (e.g. "Test Reporting").
   - **Folder** — place it in an existing folder (or Home).
   - **Starter Dashboard** — start from **Empty Dashboard** or copy/modify an **existing** dashboard.
   - **Tags** — add tags (e.g. "supervisor", "US") so dashboards can be filtered later.
   - **Auto Refresh** — interval from **10 seconds to 2 hours**.
3. **Create**.

## Organize dashboards
- **Favorite** — mark a dashboard as favorite; it appears under **Favorite Dashboards** for quick access.
- **Folders** — create a new folder (e.g. "US Reports"): choose to nest it in an existing folder or place on Home; set which **workspaces** and **users/user groups** to share it with. Then **Move to Folder** to file a dashboard into it.
- **Tags** — filter dashboards by tag (search the tag → all dashboards with it appear).

## Best practice
Use **tags**, organize into **folders**, and mark **favorites** — over time dozens of reports accumulate and become hard to manage without this hygiene.
