# Dashboard Feature Overview (Reporting 062)
**Source:** Product Foundation Courses → Reporting / 062 Dashboard Feature Overview (video transcript + Standard Care Dashboard screenshot) · **Help:** search `site:sprinklr.com/help reporting dashboard date filter clone edit layout export`

## What it is
The dashboard-level functionalities: edit/clone, edit layout, date filter, sharing, export, and more — accessed mainly from the **three-dots More Actions** menu (top-right) and the date filter.

## More Actions (three dots, top-right)
- **Edit** — change dashboard **name**, **folder**, and **tags**.
- **Clone** — duplicate the dashboard; choose the clone's name, optionally copy **share configuration** (checkbox) and **tags**.
- **Edit Layout** — reposition widgets within a section for a more readable, insight-friendly layout; **Save** to apply.
- **Delete** the dashboard.
- **Share configuration** — control which **users / workspaces** can access.
- **External link** — generate a shareable link to the dashboard for outside sources.
- **Export** — Excel, PDF, etc.; **generate a presentation**.
- **Lock** the dashboard.
- **Self-serve reset (SLF reset)** option.

## Date filter (time range)
- Standard ranges: today, yesterday, last 1 hour, last 7 / 30 / 60 / 90 days, etc.
- **Custom range** — pick start date/time and end date/time (e.g. 12:45–12:30 AM, 22 June).
- **Time zone** — set a specific zone (e.g. Asia/Qatar); data recalculates for the selected range + zone.

## Dashboard structure
- **Tabs** organize widgets (e.g. Volume, SLA, Agent Performance, Agent Availability, Live).
- Per-widget controls (edit, clone, more actions); a **text/notes widget** can describe metrics.
- Example metric definitions (Case Volume Report): **Total Messages Received**, **Engageable Message** (requires action — tagged Engageable by Intuition Moderation), **Non-Engageable Message**, **Total Published Messages**, **Total/Open/Closed Cases**, **Unique Customer Engaged**.
