# Campaigns (Journey Facilitator 141)
**Source:** Product Foundation Courses → Journey Facilitator / 141 Campaigns (video transcript + demo; Add Campaign screen screenshot) · **Help:** search `site:sprinklr.com/help create marketing campaign campaign manager`

## What it is
In Sprinklr, **campaigns** align and track marketing initiatives. They let you **categorise and organise outbound messages for reporting**, plan/collaborate with multiple stakeholders, track progress, and analyse performance. Campaigns provide a centralised platform to:
- Initiate **workflows** to automate task assignments and track progress.
- Generate **reports** on progress, engagement, reach, and more — to measure effectiveness.

## Configuration steps (demo)
1. **Open Campaigns.** New tab icon → **Sprinklr Marketing** tab → **Campaigns** (within the **Plans** section). *Ensure you're in **Marketing**, not Advertising.*
   - Alt: **Quick Publish** icon (top nav) → **Create Campaign**.
2. **Campaign Manager window** lists all existing campaigns (edit or create). Click **Add Campaign** (top-right).
3. In **Add Campaign**, fill the **Basic Properties**:
   - **Campaign Name** (descriptive, represents the initiative's purpose).
   - **Description** (brief).
   - **Start Date** + **End Date** — or tick **Evergreen Campaign** if ongoing with no end date.
   - **Status** — Draft or Approved.
   - **Tags** — associate to categorise/organise outbound messages.
   - **Visibility** — all workspaces or specific workspaces; same for **Users / User Groups** (and which users/groups subscribe to the campaign).
   - **Is Campaign confidential?** — restrict to authorised users only.
   - **Is Influencer Campaign** — tick if adding influencers.
   - **Custom Properties** / **Brief template** as needed.
4. **Save** (bottom-right) → campaign created; you land on the **Campaign Overview** tab for additional details.
